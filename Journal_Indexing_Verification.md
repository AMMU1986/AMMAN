## Caveats (important)

1. **Scopus source list ≠ active indexing.** The Scopus master list includes discontinued/de-selected titles. Presence there does not confirm a journal is *currently* covered. Entries flagged ⚠️ (e.g., #4, #9, #15) are on the list but likely historic; confirm using the Scopus "Active/Inactive" status or coverage-years column.
2. **PMC ≠ MEDLINE.** Appearing in the PubMed/PMC list means articles are searchable via PubMed through PMC full-text deposit; it is not the same as selective MEDLINE (MeSH) indexing. Bioinformation is PMC-only.
3. **Embase list type unconfirmed.** The user has not confirmed whether the supplied July 2026 Embase list was the *active source list* or a *discontinued titles* roster. If active, "✗" reliably means not indexed; if discontinued, absence is inconclusive.
4. **Web of Science and DOAJ are not included** in this file — reference lists for those two databases were not supplied, so they could not be verified the same way.
