# AMMAN - Academic Manuscripts and Research Repository

A collection of academic manuscripts, book chapters, and supporting materials for multidisciplinary research publications.

## Repository Contents

### Manuscripts

| File | Description |
|------|-------------|
| `Manuscript_Ionic_Liquids_MQL_Machining.md` | Ionic Liquids as Sustainable Lubricant Additives in MQL Machining |
| `Manuscript_Ionic_Liquids_MQL_Machining.docx` | Word format of the ionic liquids manuscript |
| `Chapter_16_AI_Assisted_Design_of_Nanomaterials.docx` | Chapter 16: AI-Assisted Design of Nanomaterials |

### Supporting Scripts

| File | Description |
|------|-------------|
| `generate_chapter.py` | Python script to generate chapter documents |
| `generate_figures.py` | Python script to generate manuscript figures |
| `create_manuscript_docx.py` | Python script to create Word documents from manuscripts |

### Directories

| Directory | Description |
|-----------|-------------|
| `figures/` | Chapter and general research figures |
| `manuscript_figures/` | Figures specific to the ionic liquids MQL machining manuscript |

## Research Areas

- AI-Assisted Nanomaterial Design
- Ionic Liquids in Minimum Quantity Lubrication (MQL) Machining
- Sustainable Manufacturing Processes
- Advanced Materials Characterization

## Usage

To generate manuscript documents:

```bash
python generate_chapter.py
python create_manuscript_docx.py
```

To generate figures:

```bash
python generate_figures.py
```
